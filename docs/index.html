Download for Mac

Apple silicon · macOS 14 or later · Free

  • In syncPlay, pause and seek on one Mac, and it happens on all of them.
  • ChatA sidebar for the party, even in fullscreen.
  • GIFs & reactionsSearch GIFs and send emoji floating over the film.
  • No serverMacs connect directly with an invite code, from any network.

Install

  1. Unzip the download and move CouchSync to your Applications folder.
  2. CouchSync isn't from the App Store, so macOS blocks it the first time. Run this once in Terminal:
    xattr -dr com.apple.quarantine /Applications/CouchSync.app
  3. Open CouchSync, pick a service from the toolbar and sign in. It keeps itself up to date from then on.
